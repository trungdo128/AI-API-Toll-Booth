# Consumer guide

1. Install Freighter and switch it to Stellar Mainnet.
2. Open the marketplace and connect the wallet; only the public address is shared.
3. Select an API and review the exact asset, amount, recipient, expiry and request hash.
4. Send the Mainnet payment from the wallet extension.
5. Submit the transaction hash to the verification endpoint.
6. Retry the protected request with the returned receipt.

Wrong-network, rejected-signature, expired-challenge and failed-transaction states do not grant access. Never enter a seed phrase or private key into the application.
