# Contributing

Open an issue before a large change. Use Node.js 22, pnpm 10.18.3 and Rust stable. Never commit secrets, wallet key material, personal user data or unverifiable evidence.

Run `pnpm test`, `pnpm typecheck`, `pnpm build`, Playwright and the Rust fmt/clippy/test/build checks documented in README. Use Conventional Commits and keep one concern per commit.
